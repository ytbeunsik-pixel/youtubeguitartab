# TAB Studio · 용의자 리드기타 플레이어

사용자가 제공한 원본 MP4와 검수된 상단 리드기타 악보를 함께 사용하는 로컬 프로그램입니다.
영상과 악보가 모두 포함되어 있으며 외부 서버에 업로드하지 않습니다.

## 실행

- 가장 간단하게: `index.html`을 Chrome/Safari/Edge에서 여세요. 같은 폴더 구조를 유지하세요.
- macOS: `실행.command`를 더블클릭하면 로컬 서버와 브라우저가 열립니다. Python 3가 필요합니다.
- 터미널: 이 폴더에서 `python3 server.py --open` 실행. 주소는 `http://127.0.0.1:8765`입니다.
- 포트가 이미 사용 중이면 `python3 server.py --port 8766 --open`을 사용하세요.
- 서버 종료: 실행한 터미널에서 Ctrl+C. 외부 네트워크 인터페이스에는 바인딩하지 않습니다.

서버 방식은 영상의 원하는 초수로 이동할 때 필요한 HTTP Range 요청을 지원합니다.
별도 패키지 설치, 계정, API 키, 인터넷 접속은 필요 없습니다.

## 동작

- **마디 클릭:** 원본 영상의 해당 마디 시작 시점으로 이동합니다. 재생 중이면 이어서 재생하고, 정지 상태에서는 정지를 유지합니다.
- **+/−:** 한 번에 반음씩 프렛 숫자와 코드 전체가 함께 바뀝니다. 초기값은 +1입니다.
- **원본으로:** 이조값을 0으로 되돌립니다.
- **현재 마디와 진행선:** 영상 재생 위치를 따라 표시됩니다. 현재 코드도 함께 표시합니다.
- **재생 따라가기:** 화면 밖의 현재 악보로 자동 스크롤합니다. 해제하면 수동으로 볼 수 있습니다.
- **싱크 조정:** 전체 마디 시작 시점을 0.05초씩 앞/뒤로 조정합니다.
- **키보드:** Space 재생/정지, ←/→ 마디 이동, +/− 이조. 버튼에 초점이 있으면 해당 버튼의 기본 동작이 우선합니다.
- **반응형 악보:** 넓은 화면에서는 한 줄 4~5마디, 좁은 화면에서는 가독성을 위해 2마디씩 표시합니다.

**키 조정은 악보에 적용됩니다. 원본 영상의 소리는 피치 변경 없이 재생됩니다.**
프렛이 0보다 작거나 24보다 커지지 않도록 이 곡에서는 -5~+8반음 범위로 제한합니다.
이조값, 싱크 보정, 따라가기 설정은 이 브라우저에만 저장합니다.

## 동기화 데이터

- 첫 마디 시작: 약 4.36초
- 템포: 109 BPM / 4분의 4박자
- 마디 간격: 240 / 109초
- 90마디 시작: 약 200.323초

영상의 재생선 색상을 추적하고 연결된 악보 좌표와 대조해 시간 기준을 추정했습니다.
현재 곡에서는 일정 템포를 적용하며, 각 마디의 `startSeconds`, `endSeconds`가 저장되어 있습니다.
반복 화면의 잘못된 연결을 교정한 기존 추출 결과를 사용했습니다.
정밀 편집이 필요하면 싱크 보정 또는 `score.js`의 개별 마디 시점을 수정하세요.

## 구성

- `index.html` / `style.css`: 연습 화면
- `app.js`: SVG 악보 렌더링, 이조, 영상 탐색, 재생 위치 연동
- `score.js`: 원본 프렛/코드와 90마디 타임코드
- `media/source.mp4`: 사용자가 제공한 원본 영상
- `server.py`: 로컬 파일 및 영상 범위 요청 제공
- `실행.command`: macOS 실행 도우미
- `verification.json`: 이번 구현의 검증 기록

`score.js`의 프렛과 코드는 **원본 값**입니다. 화면을 그릴 때 이조하므로 반복해서 +/−를 눌러도 누적 변환 오차가 생기지 않습니다.
타이, 괄호, 슬라이드, 벤딩, 비브라토 및 음 길이는 원본 구조를 유지합니다.

## 파일럿 범위

이 플레이어는 이미 검수된 이번 곡의 악보 데이터를 사용하는 프로그램입니다.
새 영상을 넣어 악보와 타임코드를 자동 생성하는 범용 인식 기능, 영상 소리의 실시간 피치 변경은 포함하지 않습니다.
기존 자동 추출/OCR 파일럿과 연결하려면, 인식 결과를 같은 악보 데이터 구조로 검수·변환하는 단계가 필요합니다.
